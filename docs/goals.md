# 招聘帖目标与差距

这份文件把职位页的要求拆成可以打勾的条目，对着仓库逐条标状态，最后回答一个问题：**「更用上 LLM」具体指哪几件事。**

原始要求见 README 附录（职位页 <https://moledao.io/jobs/moledaoofficial/ai-agent-engineer-forecasting/2471vt/>，2026-11-12 读取）。缩写第一次出现时给全称和一句人话。

## 1. 目标清单（12 条）

状态用三档：**有**（能拿出代码、数字和 trace）、**半**（有骨架，缺关键一环）、**无**。

| # | 帖子里的原话 | 落到仓库的什么 | 状态 | LLM 在哪 |
|---|---|---|---|---|
| G1 | 搭建做研究的智能体：搜索、读文档、调工具、一步步推理，给出**校准过的概率** | `src/forecast_log/agent/`（7 个带闸门的工具、8 步循环、结构化提交） | **有** | 循环本身 |

## 2. 现在的 LLM 到底干了什么

只有三处，都不在「猜数字」上：

| 用途 | 规模 | 成本 | 有没有用（按仓库自己的检验） |
|---|---|---|---|
| 拉宏观日历（FOMC / CPI / NFP 的发布日） | 129 + 192 + 192 次 | $0.0016 | **有用**：日历触发把 2015 年前那段不成立的信号救回来了 |
| 每天读新闻打标签（制度、严重度、事件） | 3487 个交易日 | 产物里没记账（prompt 一版，未统计 token） | **只当否决票**：当方向信号三层检验全没过；严重度 ≥ 0.7 之后 5 日上涨 56.8%，全部日子 59.4% |
| agent 层：选工具、读结果、写 rationale、提交概率 | 96 道评测题 + 3 道真题影子 | $0.0011/条 | **有用但不是靠脑子**：去掉工具就从 0.1631 掉到 0.2293，而带工具的 0.1631 与统计模型 0.1636 打平 |

最后一行是这份文件最重要的一条：**LLM 目前的价值全在「编排工具 + 留痕」，不在「判断方向」。** 它在纯数值题上和 0.04 毫秒的统计模型打平，成本贵 1000 倍；一旦抽掉工具，方向命中率 55.2%，还不如基率。

## 3. 「更用上 LLM」不等于换掉统计模型

所以正确的加法是：**把 LLM 放在统计模型结构上做不到的地方**，一共四件。

### A. 检索真实新闻（G12、G1）

现在 `search_news` 在评测台拿到的是空语料，因为那批历史题没有对应新闻。运行时有 GDELT + 三个 RSS，但缺**按分钟的时间戳**和真正的财经快讯，所以只能做展示，进不了信号。补上之后，agent 才有「读文档 → 推理 → 给概率」的完整链路，而不是拿价格序列算统计量。

### B. 多主体模拟（G2，完全空白）

招聘帖的职责 2 是「在政策和市场模拟中编排大量 AI 角色」。仓库里连雏形都没有：`ensemble.py` 是「同一个问题问 N 次」，不是「N 个角色各自有立场、互相影响」。这是从「预测器」变成「模拟器」的那一步，也是帖子里最不像其他候选人的加分项。

最小可行版：一个简单的经济模型（比如利率 → 信贷 → 需求的三个状态变量），N 个角色各自收到部分信息、按 LLM 给的行为函数行动，汇总出价格路径；用历史事件做回测，看模拟路径能不能覆盖真实路径。**这条的性价比最高，因为它不需要新数据源。**

### C. 开放题，而不只是价格门槛题（G1、G11）

现有 96 道评测题全是「`^VXN` 某天是否高于某阈值」。而产品说的是「政策决定、市场走向、地缘结果」。离线的开放题更难造，但可以先用已揭晓的历史事件做小样本（选举、议息、停火协议），人工写 20–30 道，题目与结算规则冻结，跑同一批预测者。**不做的后果**：agent 的评测结论只覆盖了「数值题」这一类。

### D. 生产化：服务、队列、数据库（G5、G7）

现在是文件 + CLI，`forecasts/` 靠「`lock` 拒绝覆盖」的约定而不是数据库约束。要满足「交付机构客户」这条，至少需要：一个只读 API（查某天锁定的概率和 trace）、一个任务队列（每天收盘后自动跑）、把 trace 落到数据库。**这条不涉及 LLM，但它是 G5 的硬门槛。**

## 4. 建议的顺序

| 顺序 | 做什么 | 对应目标 | 成本 | 为什么排这里 |
|---|---|---|---|---|
| 1 | 多主体政策模拟的最小可行版 | G2、G12 | 中 | 唯一的「无」，且不需要新数据源 |
| 2 | 20–30 道开放历史题 + 冻结结算规则 | G1、G11 | 低 | 把「校准概率」的结论从数值题扩到开放题 |
| 3 | 真实财经快讯 + 分钟级时间戳 | G1、G12 | 中 | 让 `search_news` 在评测里不是空实现 |
| 4 | 只读 API + 每日任务 | G5、G7 | 中 | 交付形态，和 LLM 无关但躲不过 |

不建议做的事：**用 LLM 替代统计模型去猜点位。** 自己的评测已经把这条路堵死了（0.1636 的统计模型 vs 0.2293 的无工具 agent，还贵 1000 倍）。
